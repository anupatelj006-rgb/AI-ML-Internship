# Waste Image Classification System

Skill Nexis Deep Learning Internship | Week 4 | Major Project

Classifies a photo of a waste item into: cardboard, glass, metal, paper, plastic.

## Features
- Gradio app: upload an image, same preprocessing as training, predicted category and model score
- Baseline CNN vs improved CNN vs ResNet18 transfer learning, plus an ensemble
- Confusion matrix, error analysis, Grad-CAM heatmaps of mistakes
- Calibration (temperature scaling, ECE), McNemar test, robustness test
- Model scores do not guarantee correctness (see the report and the app)

## Dataset
TrashNet (Yang and Thung, 2016): https://github.com/garythung/trashnet
5 of 6 classes used; data/ holds one folder per class (images not committed).

## Run
```
python -m pip install -r requirements.txt
python download_data.py
python main.py
python app.py
```
Quick test: python main.py --epochs 1

## Limitations
- Small dataset with controlled backgrounds; real-world photos will score lower.
- Only 5 categories; anything else is forced into one of them.
- Scores are confidence values, not guarantees of correctness.
- One split and one run per model.
