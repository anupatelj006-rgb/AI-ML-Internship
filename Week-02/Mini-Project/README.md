# Week 2: Classification & Improving Neural Networks

Skill Nexis Deep Learning Internship

| Task | Folder | What it covers |
|---|---|---|
| Assignment 2: Neural Network Comparison | `Assignment/` | Linear model vs neural network on a curved two-class dataset, settings comparison table, boundaries, confusion matrices |
| Mini Project 2: Digit Lab | `Mini-Project/` | Fully connected network on MNIST, test accuracy, confusion matrix, wrong predictions, error analysis, plus confidence, trust-threshold and stress-test experiments |

## Topics covered
Binary and multiclass classification, hidden layers and nonlinear activations, classification loss, accuracy/precision/recall, confusion matrices, underfitting and overfitting, choosing settings with validation data.

## How to run
1. Create a virtual environment and activate it
2. `pip install numpy pandas matplotlib scikit-learn torch torchvision ipykernel`
3. Assignment: open the notebook in `Assignment/` and click Run All
4. Mini Project: `cd Mini-Project` then `python main.py` (charts are saved to `outputs/`)
